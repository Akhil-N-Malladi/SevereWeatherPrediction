Project Overview

This project is a weather prediction website that provides users with a choropleth map to visualize various weather phenomena across the United States. Users can select different weather events such as extreme heat, cold, wind, hail, snowstorms, and heavy rain to see how they are distributed geographically. Additionally, users can input their latitude and longitude to get specific weather data for their location.

How this website was built

This website was built using HTML, CSS, and JavaScript. The choropleth map is created with D3.js and TopoJSON for handling geographic data. The backend is powered by Python and various machine learning libraries to process and analyze the weather data. To connect the python backend with the frontend, FastAPI was used.

The AI model

In order to accurately predict weather patterns, a XGBoost model was used. The training process took advantange of multiple optimization techniques such as ADASYN. Undersampling, SMOTE, SMOTEEN and SMOTENC were also considered. The training process also uses feature engineering to ensure to increase accuracy.

Data Sources

The weather data used in this project is sourced from the National Oceanic and Atmospheric Administration (NOAA) and Open Meteo. The data is processed and analyzed to provide accurate predictions and visualizations on the map.
